# Local Tool Agent

Ein minimaler lokaler Python-Agent mit OpenAI-kompatiblem Tool-Calling (Uhrzeit & sichere Berechnungen).

## Voraussetzungen
- Python 3.10+
- Ein laufender lokaler Modell-Server mit Tool-Calling-Unterstützung (z. B. Ollama, LM Studio oder Lemonade)

## Installation & Start
```bash
pip install -r requirements.txt
python agent.py
